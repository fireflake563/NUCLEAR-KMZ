## Requirements

- **Google Earth Pro (Desktop)**
- Windows, macOS, or Linux

> **Important:** This KMZ is designed for the **desktop version of Google Earth Pro**. It is **not compatible with Google Earth on the web or the mobile app.**

---

## Installation

1. Download the latest `.kmz` file from the Releases section.
2. Install and open **Google Earth Pro (Desktop)**.
3. Double-click the `.kmz` file, or open it from **File → Open** within Google Earth Pro.
4. Expand the folders in the **Places** panel.
5. Toggle countries on and off as desired.
6. Fly anywhere in the world to explore the visualizations.

## Quick Start

1. Download the latest `.kmz` file.
2. Open it with **Google Earth Pro (Desktop)**.
3. Expand the folders in the **Places** panel.
4. Start exploring.
